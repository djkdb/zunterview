웹 검색과 각 서비스의 공개 페이지·기사만 보고 정리했습니다. 직접 가입해 써 본 것은 아니라서, 발표 전에 주요 서비스 1~2개는 직접 써 보고 확인하세요. "확인 안 됨"은 공개 자료에서 찾지 못했다는 뜻입니다.

## 2. 기업용 AI 면접 솔루션 (직접 경쟁은 아님)

잡다 역량검사, 뷰인터HR, 에피(Effy), 몬스터, 하이버프, 텔타 등은 **회사가 지원자를 평가할 때** 쓰는 B2B 솔루션입니다. 이 중 대화형(뷰인터HR, 에피, 몬스터, 슈퍼코더)은 답변이 구체적이지 않으면 꼬리질문을 합니다(에피: 주제당 최대 4회). 출처: [슈퍼코더 비교 글](https://www.supercoder.co/blog/korean-ai-interview-services-deep-dive).

입시 면접용(면접왕: 생활기록부 기반, 수시·의대)도 있습니다([면접왕](https://interviewking.kr/)).

## 3. 정리: 무엇이 이미 있고, 무엇이 다른가

**이미 흔한 것** (이것만으로는 독창성이 되지 않음)

- 자소서·이력서 기반 맞춤 질문
- 답변에 따른 꼬리질문
- 답변 분석 리포트와 예시 답안
- 면접관 성격 선택(사람인은 6명)

가장 비슷한 것은 **사람인 AI 모의면접**입니다. 이력서와 공고 분석, 꼬리질문, 면접관 페르소나, 기업 유형별 질문까지 겹칩니다. 사람인은 실제 영상·음성 데이터로 학습한 자체 모델과 음성 합성을 쓴다고 밝혀서, 기술 규모로 비교하면 이길 수 없습니다.

**이 프로젝트가 다른 점** (발표에서 강조할 것)

| 차별점 | 근거 | 비교 |
|---|---|---|
| 직무별로 다른 꼬리질문 경로 | 256개 직무를 26개 유형으로 묶은 면접 설계도(회계: 기준 → 오류 → 처리, 간호: 환자 안전 → 상황 대응) | 꼬꼬면은 개발자만. 다른 서비스는 직무별 경로를 공개하지 않음 |
| 질문 출처 표시 | 질문마다 "공개후기 기반/공식자료 기반/직무기반" 배지. "기출"이라 부르지 않음 | 조사한 서비스 중 출처를 표시하는 곳은 찾지 못함 |
| 서류 문장을 그대로 인용해 검증 | "자기소개서에 '응답 시간을 40% 줄였습니다'라고 쓰셨는데, 측정은 어떻게…" | 다른 서비스는 "자소서 기반 질문 생성"까지만 공개 |
| 무료, 가입 없음, 카메라 없음 | API 키 없이도 MOCK 면접관으로 전체 흐름. 서버에 답변·서류 저장 안 함 | 사람인 1회 27,500원, 영상 분석은 카메라 필요 |
| 면접 태도까지 실전처럼 | 욕설·반말·무성의한 답에 면접관이 면접을 중단 | 조사한 자료에서는 확인 안 됨 |

**약점** (질문받을 수 있는 것)

- 표정·시선 같은 비언어 분석이 없다(카메라를 쓰지 않는다는 원칙과 맞바꾼 것).
- 실제 합격자 데이터로 검증한 점수가 아니다(연습용 참고 지표).
- 대규모 사용자 검증 전의 프로토타입이다.

## 4. 차별점을 더 키우는 기능 (2026-10-06 구현)

조사 결과 "자소서 질문 + 꼬리질문 + 리포트"는 이미 표준입니다. 독창성 점수를 올리려면 다른 서비스에서 보지 못한 쪽을 키우는 것이 낫습니다.

1. **막힌 질문 다시 답하기** (구현): 평가표에서 60점 아래였던 질문을 꼬리질문부터 모아 다시 답하고, 같은 면접관의 새 점수와 항목별 변화를 처음 답과 나란히 보여 준다.
2. **서류와 답변 비교** (구현): 자소서·이력서에 쓴 수치와 역할을 면접 답변과 맞춰 "다름 / 설명 부족 / 일치"로 평가표에 표시한다. "1.2초에서 0.7초"처럼 다른 단위로 말해도 변화율로 계산해 맞춰 본다. 브라우저 안에서 계산하고 어디에도 보내지 않는다.
3. **직무별 꼬리질문 순서 미리 보기** (구현): 접수 3단계에 "백엔드 개발자 면접관은 이렇게 파고듭니다"와 단계별 실제 질문, 따로 보는 직무 역량, 압박 면접의 되묻기 예시를 보여 준다.
